# 智享到家部署文档

## 1. 部署目标

当前前端项目是 React + Vite 单页应用，适合部署到：

- Linux + Nginx
- 宝塔面板静态站点
- Docker + Nginx
- 云服务器静态资源目录

当前三端不是三个独立服务，而是：

- 一个前端站点
- 三种角色登录
- 三套角色页面路由

统一登录入口：

```text
/login
```

角色首页：

```text
/         消费者端
/provider 员工端
/admin    管理端
```

## 2. 本地构建

在项目根目录执行：

```bash
npm install
npm run build
```

构建完成后，静态文件目录为：

```text
dist/
```

## 3. 方案一：部署到 Linux + Nginx

### 3.1 服务器环境建议

- Ubuntu 22.04 / CentOS 7+
- Nginx 1.20+
- Node.js 20+

### 3.2 上传项目

把整个项目上传到服务器，例如：

```bash
/home/deploy/homecare-platform
```

### 3.3 执行部署脚本

项目已经提供一键部署脚本：

```bash
cd /home/deploy/homecare-platform
chmod +x scripts/deploy-server.sh
bash scripts/deploy-server.sh
```

脚本会自动完成：

- 安装依赖
- 构建前端
- 同步 `dist` 到 `/var/www/homecare-platform`
- 写入 Nginx 配置
- 检查并重载 Nginx

### 3.4 默认部署目录

```text
/var/www/homecare-platform
```

### 3.5 默认 Nginx 配置位置

```text
/etc/nginx/conf.d/homecare-platform.conf
```

## 4. 推荐方案：单机 Docker 一键启动

如果你希望把前端、网关、后端骨架、MySQL、Redis 一起部署到同一台服务器，推荐使用项目自带的单机 Docker 方案。

### 4.1 服务器准备

- Linux 服务器
- 已安装 Docker
- 已安装 Docker Compose

### 4.2 启动命令

在项目根目录执行：

```bash
chmod +x scripts/start-single-host.sh
bash scripts/start-single-host.sh
```

### 4.3 停止命令

```bash
chmod +x scripts/stop-single-host.sh
bash scripts/stop-single-host.sh
```

### 4.4 相关文件

```text
deploy/docker-compose.yml
backend/Dockerfile
Dockerfile
deploy/nginx.conf
scripts/start-single-host.sh
scripts/stop-single-host.sh
```

### 4.5 启动后默认访问地址

```text
http://服务器IP/login
```

### 4.6 默认容器说明

- `frontend`：前端静态站点 + Nginx
- `gateway-service`：网关服务
- `auth-service`：认证服务骨架
- `order-service`：订单服务骨架
- `staff-service`：员工服务骨架
- `payment-service`：支付服务骨架
- `mysql`：MySQL 8.0
- `redis`：Redis 7

### 4.7 默认端口

- `80`：前端站点
- `8080`：gateway-service
- `8081`：auth-service
- `8082`：order-service
- `8083`：staff-service
- `8084`：payment-service
- `3306`：MySQL
- `6379`：Redis

## 5. 方案二：手动部署静态文件

如果你不想跑脚本，也可以手动部署。

### 4.1 本地构建

```bash
npm run build
```

### 4.2 上传 `dist` 目录

把 `dist` 中的所有文件上传到服务器站点目录，例如：

```text
/www/wwwroot/homecare-platform
```

### 4.3 Nginx 配置重点

因为这是单页应用，必须配置：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

否则刷新 `/provider`、`/admin`、`/orders` 这类路由时会出现 404。

项目内已提供参考配置文件：

```text
deploy/nginx.conf
```

## 6. 方案三：Docker 部署

项目已提供：

- `Dockerfile`
- `.dockerignore`
- `deploy/nginx.conf`

### 5.1 构建镜像

```bash
docker build -t homecare-platform:latest .
```

### 5.2 启动容器

```bash
docker run -d \
  --name homecare-platform \
  -p 8080:80 \
  homecare-platform:latest
```

### 5.3 访问地址

```text
http://服务器IP:8080/login
```

## 7. 宝塔面板部署建议

如果你使用宝塔：

1. 新建一个站点
2. 站点目录指向静态文件目录
3. 上传 `dist` 内全部文件到站点根目录
4. 在站点 Nginx 配置中加入：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

5. 重载 Nginx

## 8. 域名访问建议

假设你的域名是：

```text
https://homecare.example.com
```

推荐入口：

- `https://homecare.example.com/login`
- `https://homecare.example.com/`
- `https://homecare.example.com/provider`
- `https://homecare.example.com/admin`

## 9. 上线前检查清单

- 已执行 `npm run build`
- 已上传最新 `dist` 文件
- Nginx 已配置 `try_files`
- 服务器防火墙已放行 80 / 443 端口
- 域名已正确解析到服务器 IP
- 刷新 `/provider`、`/admin`、`/orders` 不会 404

## 10. 当前项目的部署边界

当前可直接上线的是前端站点。

已具备：

- 三角色登录入口
- 消费者端、员工端、管理端页面
- 前端业务联动
- 静态部署能力

当前后端仍属于课程骨架和 mock 阶段，正式生产上线前还需要继续完善：

- Spring Cloud 服务真实接口
- 统一认证与 token
- MySQL / Redis / Nacos
- 支付、退款、投诉、改约真实服务
- 日志、监控、风控与权限审计

## 11. 最简单的上线结论

如果你现在只是想把这个前端项目放到服务器给老师或别人访问，最短路径就是：

1. 执行 `npm run build`
2. 上传 `dist` 到服务器站点目录
3. Nginx 配置 `try_files`
4. 通过 `/login` 访问
