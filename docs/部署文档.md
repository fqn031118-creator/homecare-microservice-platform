# 部署与维护

准确启动命令、环境变量与账号见仓库README。新库只运行一次sql/install.sql；旧库先备份、检查重复支付和孤立引用，再运行一次sql/upgrade_v2.sql。升级脚本不自动识别已执行版本，不能重复运行。

默认不开启demo profile，不自动创建教学账号。demo仅供隔离教学环境，示例密码不用于公网。已有明文密码需管理员重置为BCrypt；SHA-256摘要可在成功登录后迁移。真实部署使用独立数据库用户和随机密码，启用HTTPS并补登录限流。

前端VITE_AUTH_API_BASE为构建期变量；本地默认http://127.0.0.1:8081/api/auth，Docker构建为/api/auth，Nginx同源代理核心服务。生产同源部署无需开放远程CORS。浏览器会话为2小时，注销后服务端删除摘要。

Docker Compose包含MySQL健康检查；数据库不对宿主机公开。初始化只在空数据卷发生，已有卷需手动迁移。当前执行环境没有Docker，因此不把Compose启动写为已验证。

上线前还需验证MySQL 8.0实际环境、数据库备份恢复、容器启动与异常恢复、HTTPS、日志脱敏、账号权限、分页性能和资源限制。不得使用测试脚本操作生产库，测试脚本会新增账号和订单。
