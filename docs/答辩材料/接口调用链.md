# 接口调用链

1. 用户登录：`Web -> gateway-service -> auth-service`
2. 创建订单：`Web -> gateway-service -> order-service`
3. 支付订单：`Web -> gateway-service -> payment-service -> order-service`
4. 自动/手动派单：`后台 -> gateway-service -> staff-service / order-service`
5. 服务人员接单：`服务人员端 -> gateway-service -> staff-service -> order-service`
6. 订单评价：`Web -> gateway-service -> order-service`

前端当前已经通过 `src/api.js` 抽象出调用层，后续只需把 mock dispatch 替换为真实 HTTP 请求即可。
