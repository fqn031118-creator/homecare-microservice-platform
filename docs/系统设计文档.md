# 智享到家系统设计文档

## 1. 项目概述

项目名称：`智享到家 - 家政服务预约微服务平台`

项目定位：面向家庭用户、服务人员与平台管理员，提供在线预约、订单支付、平台派单、上门服务与评价闭环的一体化家政服务平台。

前端演示地址：

- 用户端首页：`/`
- 登录页：`/login`
- 下单页：`/booking`
- 订单页：`/orders`
- 服务人员端：`/provider`
- 管理后台：`/admin`
- 运维监控：`/ops`

## 2. 目标用户

### 2.1 家庭用户

- 浏览服务项目
- 选择服务人员
- 创建预约订单
- 跟踪订单状态
- 完成支付与评价

### 2.2 服务人员

- 查看待接单任务
- 接单与开始服务
- 完成服务并回传状态
- 查看任务历史

### 2.3 平台管理员

- 查看订单总览
- 手动或自动派单
- 监控履约进度
- 查看营收与告警信息

## 3. 业务流程

1. 用户登录系统。
2. 用户浏览服务市场并进入下单页。
3. 用户选择服务、服务人员、预约时间、地址并提交订单。
4. 系统生成订单，初始状态为 `待支付`。
5. 用户完成支付后，订单状态变更为 `待派单`。
6. 后台调度系统或管理员将订单分配给服务人员，状态变更为 `已派单`。
7. 服务人员在工作台接单，状态变更为 `已接单`。
8. 服务人员点击开始服务，状态变更为 `服务中`。
9. 服务完成后，状态变更为 `已完成`。
10. 用户提交评分与评价后，订单状态变更为 `已评价`。

## 4. 微服务拆分设计

### 4.1 gateway-service

- 系统统一入口
- API 路由转发
- JWT 鉴权拦截
- 接口限流

### 4.2 auth-service

- 用户登录
- Token 签发与校验
- 角色权限管理

### 4.3 user-service

- 用户基本资料
- 联系方式管理
- 地址簿管理

### 4.4 service-item-service

- 服务分类管理
- 服务项目管理
- 标签与价格管理

### 4.5 order-service

- 订单创建
- 订单状态流转
- 预约时间管理
- 评价数据入口

### 4.6 staff-service

- 服务人员资料
- 技能标签
- 接单状态
- 排班与空闲时间

### 4.7 dispatch-service

- 订单派单
- 服务区域匹配
- 服务人员调度
- 简单优先级策略

### 4.8 payment-service

- 模拟支付
- 支付结果回调
- 对账记录

### 4.9 report-service

- 营收统计
- 订单分析
- 履约指标
- 服务人员绩效

## 5. 系统架构说明

### 5.1 技术栈

- 前端：`React + Vite + Tailwind 风格工具类`
- 后端建议：`Spring Boot + Spring Cloud`
- 数据库：`MySQL 8`
- 缓存：`Redis`
- 注册中心：`Nacos` 或 `Eureka`
- 网关：`Spring Cloud Gateway`
- 熔断限流：`Sentinel`
- 配置中心：`Nacos Config`
- 消息机制建议：`RabbitMQ` 或 `Kafka`

### 5.2 架构分层

- 表现层：用户端、服务人员端、管理后台、监控中心
- 网关层：统一入口与权限控制
- 业务服务层：订单、支付、人员、服务、报表
- 数据层：MySQL、Redis、对象存储

## 7. 非功能性要求

### 7.1 可扩展性

- 服务按业务边界拆分
- 订单状态流转可扩展
- 前端状态结构已预留多角色联动

### 7.2 安全性

- 登录鉴权
- 网关统一鉴权拦截
- 用户手机号等敏感数据应脱敏显示

### 7.3 可维护性

- 文档、SQL、部署脚本集中管理
- 前端页面与共享状态分离
- 微服务职责清晰

### 7.4 可演示性

- 支持多角色切换
- 支持核心业务闭环演示
- 支持运维监控和后台调度场景展示
