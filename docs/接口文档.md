# 智享到家接口文档

## 1. 接口规范

- 协议：`HTTP/HTTPS`
- 风格：`RESTful`
- 数据格式：`application/json`
- 统一前缀：`/api`

统一返回结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

## 2. 认证模块

### 2.1 用户登录

- 方法：`POST`
- 路径：`/api/auth/login`

请求参数：

```json
{
  "phone": "13800000000",
  "password": "123456"
}
```

返回示例：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "jwt-token-demo",
    "userId": 1,
    "name": "林然",
    "role": "customer"
  }
}
```

## 3. 服务项目模块

### 3.1 查询服务列表

- 方法：`GET`
- 路径：`/api/services`

查询参数：

- `category`
- `keyword`

### 3.2 查询服务详情

- 方法：`GET`
- 路径：`/api/services/{id}`

## 4. 服务人员模块

### 4.1 查询服务人员列表

- 方法：`GET`
- 路径：`/api/providers`

查询参数：

- `serviceId`
- `area`
- `status`

### 4.2 查询服务人员详情

- 方法：`GET`
- 路径：`/api/providers/{id}`

## 5. 订单模块

### 5.1 创建订单

- 方法：`POST`
- 路径：`/api/orders`

请求参数：

```json
{
  "serviceId": "svc-001",
  "providerId": "provider-2",
  "appointmentTime": "2026-06-03 10:00:00",
  "address": "徐汇区漕溪北路 66 号",
  "remark": "提前电话联系"
}
```

### 5.2 查询我的订单

- 方法：`GET`
- 路径：`/api/orders/my`

### 5.3 查询订单详情

- 方法：`GET`
- 路径：`/api/orders/{orderId}`

### 5.4 支付订单

- 方法：`POST`
- 路径：`/api/orders/{orderId}/pay`

### 5.5 提交评价

- 方法：`POST`
- 路径：`/api/orders/{orderId}/review`

请求参数：

```json
{
  "rating": 5,
  "content": "服务准时，处理非常专业。"
}
```

## 6. 派单模块

### 6.1 自动派单

- 方法：`POST`
- 路径：`/api/dispatch/{orderId}/auto`

### 6.2 手动派单

- 方法：`POST`
- 路径：`/api/dispatch/{orderId}/manual`

请求参数：

```json
{
  "providerId": "provider-1"
}
```
