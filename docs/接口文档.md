# 接口文档

开发默认 `http://127.0.0.1:8081`。JSON输入输出；除注册、登录、手机号检查外，业务接口要求 `Authorization: Bearer <token>`。令牌有效2小时，服务端存摘要。统一业务错误为 `{"message":"原因"}`，400参数错误、401未登录或过期、403权限/归属不符、404不存在、409重复或状态冲突。

## 认证

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| POST | /api/auth/register | name phone password confirmPassword | 201，success message user token |
| POST | /api/auth/login | phone password | 200，同上 |
| GET | /api/auth/phone-exists?phone=... | 手机号 | exists |
| GET | /api/auth/me | Bearer | 用户视图 |
| PUT | /api/auth/profile | name phone avatar，可选id | success message user |
| POST | /api/auth/logout | Bearer，空对象 | 200，撤销会话 |

注册姓名1至50字符、手机号1开头11位、密码至少8字符且UTF-8编码不超过72字节、确认一致。用户视图含id/name/phone/role/level/avatar，不含密码。资料修改身份来自会话；请求中其他用户id返回403。

## 订单与人员

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | /api/platform/snapshot | 角色范围订单、服务目录、人员档案、本人provider编码 |
| POST | /api/platform/orders | 消费者创建订单 |
| POST | /api/platform/orders/{orderNo}/{operation} | 状态动作 |
| PUT | /api/platform/provider/online | 服务人员设置online布尔值 |

创建字段：serviceId、dateKey、address、contactName、contactPhone、remark。dateKey格式 `yyyy-MM-dd HH:mm`，统一Asia/Shanghai语义；至少提前30分钟。金额只由数据库服务价格加15元服务费计算，客户端amount无效。下单不指定人员，支付后人工派单或接单。

动作请求均为JSON，可选version用于过期版本冲突检查；实际并发正确性由事务与行锁保证。

| operation | 角色 | 字段 | 规则 |
|---|---|---|---|
| pay | 订单本人 | 无 | 待支付→待派单；重复已支付返回当前订单；mock渠道 |
| assign | admin | providerId | 待派单→已派单；人员须绑定账号、在线且空闲 |
| accept | provider | 无 | 待派单/已派单→已接单；禁止他人任务，须在线 |
| start | 本人人员 | 无 | 已接单→服务中 |
| complete | 本人人员 | 无 | 服务中→已完成 |
| review | 订单本人 | rating review | 已完成→已评价；评分整数1至5，评价1至500字符 |
| cancel | 订单本人 | reason | 仅待支付可取消 |
| reschedule | 订单本人 | dateKey | 仅待支付/待派单，至少提前30分钟 |
| refund | 订单本人 | reason | 已支付、尚无申请，仅记录处理中，不执行真实退款 |
| complaint | 订单本人 | content | 尚无投诉，仅记录处理中 |

快照中消费者仅见本人订单；管理员可见全部；人员可见本人任务与待派单池。池中客户姓名、电话、详细地址、备注被遮蔽。接单/派单后任务人员获得履约必需信息。

订单视图兼容前端字段，包括id（order_no）、customerId、serviceName、providerId（provider_code）、status、amount、时间、售后字段、rating/review/version。快照暂未分页，适用于课程数据量。
